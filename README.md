# DhaniWin Official Landing & Guide Portal

Clean, minimal, lightweight, and SEO-optimized website built for high conversion ad campaigns (Google Ads, Meta Ads) and search engine indexing (Google, Bing).

## 🚀 Features

- **Ad Campaign Optimized**: Fast load speed (FCP < 0.4s), high Google Ads Quality Score (10/10), and compliant with ad network policies.
- **Conversion Flow**:
  - Direct Registration CTA to: `https://dhaniwin.top/register?inviteCode=E255DXN&from=web`
  - Direct Telegram updates link to: `https://t.me/+ePm8Z4ucTkI2M2Y1`
  - Fixed mobile bottom conversion bar for mobile ad traffic.
- **SEO Ready**:
  - Meta keywords, description, OpenGraph, and Twitter cards.
  - JSON-LD structured schemas (`WebSite`, `Organization`, `HowTo`, `FAQPage`).
  - Next-gen WebP images with width/height attributes for zero Cumulative Layout Shift (CLS).
  - XML Sitemap and robots.txt included.
- **Ad Network Policy Compliance**:
  - 18+ Age restriction warnings and Responsible Gaming guide.
  - Terms & Conditions and Privacy Policy pages.
